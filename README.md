# Sociedade do Dragão [BR]

Módulo para o Blish HUD desenvolvido para a guilda Sociedade do Dragão [BR], do Guild Wars 2.

## 🛠️ Desenvolvimento

Este módulo foi desenvolvido em C# para o [Blish HUD](https://blishhud.com/).

### Requisitos

- Guild Wars 2
- Blish HUD
- .NET Framework 4.7.2
- Visual Studio / Visual Studio Code
